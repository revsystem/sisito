## 学び

- Herdrスペース内には対話型のCursor Agent（`w9:p2`、cwd = このリポジトリ、過去にPR #35のCVEレビュー実績あり）が常駐しており、`herdr agent prompt <pane> "<text>" --wait --until working`で送信、`herdr agent wait <pane> --until idle --until done`で完了待機、`herdr pane read <pane> --source recent-unwrapped --lines N`で結果取得という手順でやり取りできる。ユーザーが「Cursor Agentにレビューを依頼して」と言うとき、CLIの`cursor-agent --print`単発呼び出しではなく、こちらのHerdrスペース内エージェントを指している場合がある（本セッションで明示的に指摘された）
- `herdr agent prompt`（テキスト送信+提出を一括で行う）を使うべきで、`herdr pane run`（生のテキスト+Enter送信）だと対話型UIの入力欄にテキストが残ったまま提出されないことがある。詰まったら`herdr pane send-keys <pane> ctrl+a`→`ctrl+k`で入力欄をクリアしてから`herdr agent prompt`を使う
- Herdrの実際のCLIサブコマンドは`herdr agent wait`/`herdr pane wait-output`であり、`herdr --skill`が返すドキュメント上の`herdr wait output`/`herdr wait agent-status`という表記とは異なる（バージョン差異の可能性）。`herdr --help`→`herdr agent --help`で実際のサブコマンド名を確認してから使う
- Rails fixturesには`DEFAULTS`（大文字）という予約キー名があり、`ActiveRecord::FixtureSet`が無条件に無視する（`lib/active_record/fixtures.rb`にドキュメント化された挙動）。YAMLアンカー用のダミー行を自作する必要は無い
- `ActiveRecord::Schema.define`は`assume_migrated_upto_version`経由で、`schema.rb`の対象バージョンより前の全マイグレーションファイルを実行せずに`schema_migrations`へマーク済みにする。したがって非決定的なデータ投入マイグレーション（`db/migrate/20170128144003_example_data.rb`）があっても、`db:schema:load`を使う限り実行されない
- `quoted_date`（activerecord）は`default_timezone == :local`のとき`Time`値に`.getlocal`を呼ぶ。YAML(Psych)がオフセット無し日時をUTCとして解釈しローカル変換して返すため、fixturesの日時literal は実際にはプロセスのTZに依存して格納値が変わる
- Ruby: `[1,2,3].slice(3..-1)`は`nil`ではなく`[]`を返す（配列長と開始位置が等しい場合）。配列長を超える場合のみ`nil`。この違いが`etc: 0`混入バグの直接の原因だった
